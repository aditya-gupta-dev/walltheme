# Support

Report bugs and request features at https://github.com/aditya-gupta-dev/walltheme/issues.

For generation failures, choose **Show Logs**, or open **View → Output → WallTheme**.
Include your VS Code version, operating system, image format, steps to reproduce, and relevant output. Review logs before sharing: they can contain local image paths.

If generated colors have not loaded, select **Reload Window** in the notification. Existing user or workspace color customizations keep their usual precedence over themes.

Supported image formats are PNG/JPEG/GIF/BMP/TIFF. Convert WebP/AVIF to PNG/JPEG before selecting them. No additional runtime is needed.
