# Changelog

## 0.1.0

- Generate Material You palettes from locally selected images or hex colors.
- Apply dark and light standalone JSON themes with UI, TextMate, and semantic code colors.
- Preserve generated palettes and themes in JSON history, with export and file browsing commands.
- Support normal theme switching and restore the previous selection with Reset Theme.
- Watch the selected image and offer Reload Window when installed theme files change.
- Decode PNG/JPEG/GIF/BMP/TIFF using bundled JavaScript; omit native decoder binaries and WebP/AVIF support for a small platform-independent VSIX.
- Correct BMP channel ordering, TIFF decoding, and GIF first-frame placement.
